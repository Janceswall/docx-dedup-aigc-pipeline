# 降查重 + 降 AIGC 改写手法

两件事要一起做，但机制完全不同：

- **查重**（知网）比对的是**字面连续重合**，连续 13 字相同即标红 → 靠**换表达**
- **AIGC 检测**（知网）看的是**文本统计特征**：句式是否过分工整、连接词是否过密、
  有没有具体细节和个人经验 → 靠**打散节奏、增加"人味"**

只做同义替换能降查重，但对 AIGC 率几乎无效；反过来只打散句式，重合片段照样标红。
**一轮同时处理两件事**，避免改两遍。

## 一、降查重：三个层面

### 词句层
- 同义替换：方法→路径；影响→作用；显著→明显
- 主动被动互换："A 促进了 B" → "B 受 A 推动"
- 指代替换：重复出现的全称改为"该做法/这一结果"

### 句式层
- 长句拆短、短句并长
- 语序调整：状语、定语从句提前或后置
- 因果句换表述："因为 A 所以 B" → "B 的出现可由 A 解释"
- 定义句换表述："X 是指……" → "所谓 X，即……"

### 段落层
- 调换论述顺序：原"现象→原因→结论"改为"结论先行→证据→解释"
- 合并同类句、拆分杂糅句
- 直接引述改概括转述（保留出处）
- 图文化、表化

## 二、降 AIGC：识别 AI 写作的"指纹"

AI 生成段落通常有这些特征，逐条对照消除：

| AI 指纹 | 典型表现 | 破法 |
|---|---|---|
| 连接词堆叠 | 因此 / 从而 / 不仅……而且 / 在这个过程中 / 通过这样的措施 / 总之 | 删掉一半，改用零连接词的自然承接 |
| 句式等长 | 连续几句都是 25~35 字，结构平行 | 故意插短句（4~10 字），长短交错 |
| 完美并列 | "既……又……""一方面……另一方面……"成串出现 | 拆掉并列结构，改成递进或转折 |
| 抽象空泛 | "具有重要价值""产生深远影响" | 换成具体做法、具体场景、具体数字 |
| 缺少主体 | 通篇都是"我们应当……""用户可以……"这类无主句式 | 加入实践者视角："在实际操作中发现……""试过一次……" |
| 三段式排比 | "活动前……活动时……活动后……" | 打散重排，或把其中一段合并进叙述 |
| 收尾套路 | "总之……不仅……而且……为……奠定了良好基础" | 换一个更朴素的落点，或落在具体效果上 |

**实战经验**：纯"同义替换"往往只能改动表层措辞，整段的句子骨架仍在，
13 字连续重合常剩下数十处、最长可达上百字。**必须靠检测器驱动，改 2~3 轮**。

## 三、必须保留、不要动的

- 引文原文（名言、诗句、法条等，在引号内属合规引用）
- 书名、人名、年份、机构名、标准全称
- 专有名词列表（术语集、名称罗列）
- 数据、案例细节、结论

这些造成的重合是无法也无需消除的，**在自检报告里如实列出**，让用户知道剩余重复来自哪里。

## 四、不能做的事

- 不改数据、不改结论、不张冠李戴
- 不用"的/了/进行/开展"凑字——读不通，也降不了多少
- 不改变学术立场与逻辑
- 不代写、不洗稿、引用他人成果必须标注
- 引用他人作品做压缩时，用省略号（……）标明删节，不要直接改引文内容

## 五、自检清单

- [ ] 段落数、段落顺序、标题、关键词、参考文献一字未动
- [ ] 原文的"摘要：""关键词："等标签前缀仍在
- [ ] ≥13 字非引用重合已清零（用 check_overlap.py 验证）
- [ ] 剩余重合片段全部可解释（引文/书名/专名）
- [ ] 未改写段落逐字节一致，段落属性 pPr 零改动
- [ ] 数据、人名、年份、案例细节与原文一致
- [ ] 通读一遍，不出现别扭的凑字和语义漂移
- [ ] 明确告知用户：最终以学校认可的系统复检为准
