# 保意改写手法（text-paraphrase）

> **本文件是 `docx-dedup-aigc-pipeline` 的组成子技能之一。**
>
> 分工：**本子技能只管「怎么换一种说法而不改意思」**——这是压查重率的正面对策。
> 压 AIGC 检测率靠的是另一套手法（打散句式节奏、增加具体细节与个人经验），
> 见兄弟子技能 `../de-ai-flavor/`。
> 两件事必须**同一轮做完**：只换词能降查重但对 AIGC 率几乎无效；
> 只打散句式则重合片段照样标红。

## 何时被调用

主技能 `docx-dedup-aigc-pipeline` 在 Step 3「改写」时加载本子技能，用于
逐段处理「重复高发段落」。典型触发场景：

- 查重报告显示某段被标红 / 标橙
- 直接引用文献过多，需要改成间接转述
- 大段照抄了某篇文献的表述，需要改成自己的话

## 三层手法

详细手法库见 `references/rewriting-techniques.md`，尺度校准见
`references/before-after-examples.md`。三层由浅入深：

### 词句层
- 同义替换：方法 → 研究路径；影响 → 作用机制；显著 → 明显
  （**学科术语不可乱换**，换了就不专业了）
- 主动被动互换："A 促进了 B" → "B 受到 A 的促进作用"
- 指代变化：重复出现的全称改为"该变量""上述做法""这一结果"

### 句式层
- 长短句互换；语序调整（状语、定语从句提前或后置）
- 因果句换表述："因为 A 所以 B" → "B 的出现，可由 A 来解释"
- 定义句换表述："X 是指……" → "所谓 X，即……"

### 段落层（最有效）
- **调换论述顺序**："现象 → 原因 → 结论" 改为 "结论先行 → 证据 → 解释"
- 合并同类句、拆分杂糅句
- 直接引述改为概括转述（保留出处标注）
- 图表文字化 / 文字图表化

## 关键纪律

**换词是下策，重组结构才是上策。** 经验上，只做"同义替换"的第一轮改写，
≥13 字的连续重合往往仍剩**数十处、最长可达上百字**——因为整段的
句子骨架没动。真正把数字压下来的是第二轮、第三轮的**拆句重组**。

因此本子技能产出的每一段，都要能通过主技能的
`scripts/check_overlap.py` 检测：与原文的 ≥13 字连续重合必须为零
（引文原文、书名、专名全称除外）。

## 输出格式

逐段输出，不要混在一起：

```text
【段落】p07
【原文】……
【改写后】……
【用到的手法】句式重构（长句拆短 + 语序调整）
【自检】原意一致 ✓ | 数据未动 ✓ | 术语未动 ✓ | 通顺 ✓
```

## 边界

- **只做保意改写**：不改数据、不改结论、不改学术立场
- 专业术语、人名、年份、机构名、标准全称、公式、公认结论一律保留
- 不用"的/了/进行/开展"凑字——读不通，也降不了多少
- 不代写、不洗稿；引用他人成果必须合规标注
- 压缩引文时用省略号标明删节，不要直接改引文内容
- 降重效果取决于查重系统算法，最终以学校认可的系统复检为准
