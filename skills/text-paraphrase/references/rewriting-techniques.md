# 论文降重改写手法库

用于 Step 3 逐句/逐段改写。核心原则：**保留原意与学术准确性，只换表达，不改观点、不改数据、不杜撰**。

## 一、词句层（同义替换）

- 同义词/近义表达：方法→研究路径；影响→作用机制；显著→明显（注意学科术语不可乱换）
- 主动被动互换："A 促进了 B" → "B 受到 A 的促进作用"
- 肯定/否定双重否定互换："有效" → "并非无效"（慎用，保持自然）
- 指代变化：把重复出现的全称换成"该变量/上述方法/这一结果"

## 二、句式层

- 长句拆短句、短句并长句
- 调整语序：把状语、定语从句提前或后置
- 因果句换表述："因为A所以B" → "B 的出现，可由 A 来解释"
- 定义句换表述："X 是指……" → "所谓 X，即……"

## 三、段落层（段落重构）

- 调换论述顺序：原"现象→原因→结论"改为"结论先行→证据支撑→原因解释"
- 合并同类句、拆分杂糅句
- 把直接引述改为概括转述（原意不变，加自己的衔接）
- 图表文字化、文字图表化（结论用表/图呈现，正文只做解读）

## 四、引用与规范

- 直接引用超过查重阈值时，改为间接转述并标注出处
- 公式、定理、公认结论属公共知识，通常不参与降重，不必硬改
- 专业术语、人名、年份、数据必须与原文一致，不可替换

## 五、不能做的事

- 不改数据、不篡改结论、不张冠李戴
- 不通过乱加"的/了/进行/开展"等凑字降重，会读不通
- 不改变学术立场与逻辑
- 降重是降低重复率，不是洗稿剽窃他人观点而不标注；引用他人成果须合规标注
